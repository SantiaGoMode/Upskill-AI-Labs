The learning experience

Training that behaves like work.

Each lab combines a realistic brief, imperfect evidence, explicit AI boundaries, and an artifact a facilitator can inspect.

01

Evidence before generation

Learners choose which sources are allowed, preserve citations, and separate supported facts from assumptions before asking a model to help.

Internal · allowedConfidential · manual reviewUnknown · clarify
02

Provider choice

Use conservative Gemini tests, OpenAI, Anthropic, or local Ollama without changing the learning workflow.

03

Observable runs

See model output, trace details, token usage, and estimated cost instead of hiding the mechanics.

04

Durable progress

Save learner-owned attempts, resume prior work, and submit an artifact for deterministic rubric feedback.

05

Synthetic enterprise

Practice inside Northwind’s Project Beacon without exposing customer or company information.
